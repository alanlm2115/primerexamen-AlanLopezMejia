## Accesibilidad (a11y)

- Agregue un enlace de "Saltar al contenido" para que se pueda ir directo al contenido principal sin usar el mouse.
- Puse estilos para que se vea bien el foco al moverse con el teclado (usando Tab).
- Revise que se pueda navegar por toda la pagina solo con el teclado (enlaces y botones).
- A las imagenes les puse texto alternativo (alt) para que el lector de pantalla las pueda leer.
- Use una clase para que la palabra "Precio" se lea aunque no se vea (sirve para accesibilidad).
- Solo use aria-label en la navegacion y aria-current para marcar la pagina actual, sin usar mas.
